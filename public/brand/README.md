# Identidad visual

El logo se obtuvo de la web pública de la Municipalidad de San Francisco el 7 de octubre de 2026 para este trabajo práctico local.

- Fuente: https://www.sanfrancisco.gov.ar/theme/imagenes/estructura/Logo_Institucional_blanco.png
- Referencia visual: https://www.sanfrancisco.gov.ar/
- Quicksand: Google Fonts, licencia SIL Open Font License incluida en `public/fonts/OFL-Quicksand.txt`.

Colores contrastados en el CSS público: celeste #009ee2, azul oscuro #1e2939, verde #6aa435, naranja #f07e07 y amarillo #f4c000. Los botones y textos usan variantes más oscuras cuando hace falta contraste. El proyecto no es un canal municipal publicado; las operaciones permanecen en localhost.
